# نظام الحضور والانصراف الذكي والرواتب (GeoAttend Pro - Flask + SQLite/MySQL)

## المميزات المنفذة بالكامل
1. **التحقق من اللوكيشن (Geofencing)**: حساب المسافة الفعلي بمعادلة Haversine بالمتر ومقارنتها بنطاق مقر العمل المحدد من الأدمن.
2. **التقاط الصورة الإجباري (Camera Verification)**: التقاط صورة حية من كاميرا الموبايل أو اللابتوب وختمها بالوقت والإحداثيات عند الحضور (IN) والانصراف (OUT).
3. **صلاحيات الأدمن والموظفين (Admin & Users)**:
   - الأدمن يحدد لكل موظف: المرتب الشهري الأساسي، أيام العمل، ميعاد بداية الشيفت ونهايته (من - إلى)، وسعر خصم الساعة.
4. **قاعدة السماح والخصم التلقائي**:
   - فترة سماح **15 دقيقة** (ربع ساعة) من بداية شيفت كل موظف بدون أي خصم.
   - بعد الـ 15 دقيقة يتم حساب الخصم تلقائياً **بالساعة** وخصمه من صافي الراتب الشهري.

## طريقة التشغيل على جهازك
```bash
pip install -r requirements.txt
python app.py
```
ثم افتح المتصفح على `http://127.0.0.1:5000`.
